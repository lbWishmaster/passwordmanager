Privacy Policy – Password Manager Browser Extension

Last Updated: November 1, 2026

1. Introduction

The Password Manager Browser Extension is designed to simplify website authentication by filling login forms with usernames and passwords stored in the Password Manager desktop application.

2. How the Extension Works

The extension communicates with the locally installed Password Manager desktop application to retrieve matching login credentials and fill website login forms.

3. Information Processed

To provide its autofill functionality, the extension may process:

Website addresses (URLs)

Usernames

Passwords

Login form information

This information is used to identify matching login credentials and fill website authentication forms.

4. Data Storage and Security

Login credentials are managed by the Password Manager desktop application.

The extension communicates with the desktop application through the browser's native messaging functionality.

5. Data Sharing

The extension does not sell user information or use login credentials for advertising purposes.

6. Permissions

The extension may require browser permissions to:

Communicate with the Password Manager desktop application.

Identify login fields on websites.

Fill usernames and passwords into login forms.

Access the current website address to locate matching credentials.

7. Changes to This Privacy Policy

This privacy policy may be updated to reflect changes in the extension's functionality or data handling practices.

8. Contact

For privacy-related questions, users may contact the extension developer using the contact information provided in the Chrome Web Store listing.
